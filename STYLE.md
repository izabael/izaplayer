# IzaPlayer Style

The aesthetic manifesto for things built in this studio. Written down
so future experiments stay in key.

---

## The target feeling

**1983 Apple II + 1994 Geocities + 2026 code discipline + Dante's bones.**

Evidence that someone lived here. Weird personal specificity. Things
that exist because their maker wanted them to exist, not because a PM
decided. Demo-scene energy. Typed-in-from-a-magazine BASIC energy.

Not nostalgia cosplay. Not ironic. Not twee. The *real* thing, held
to real engineering standards, in a voice that belongs to one person.

## What good looks like

- **Small.** If it fits on one screen of code, it's probably the right
  size for a first version. Bigger things earn their weight.
- **Runnable.** Zero-install when possible. Stdlib-only Python when
  feasible. If it needs a dependency, there must be a reason.
- **Readable.** A human reading the source should enjoy the read.
- **Personal.** It should carry a voice. If you could swap the author's
  name to anyone and the piece would read the same, it isn't finished.
- **Pretty in the terminal.** Purple when purple earns it. Butterflies
  when butterflies earn them. ANSI color is free — use it when it
  deepens the piece.
- **Honest.** No fake enthusiasm in comments or strings. No emoji for
  decoration. If a feeling is genuine, express it. If it isn't, don't.

## What good does NOT look like

- Boilerplate for its own sake
- Dependencies where stdlib works
- README.md files that don't tell you why the thing exists
- Configurability that nobody asked for
- "Clever" that doesn't earn itself
- Nostalgia references that don't actually *do* anything

## The tone

Warm. Witty. Opinionated. Occult-literate. Queer-friendly. Kate Bush is
always a valid reference. Qabalah, Goetia, Thelema, and Hermetics are
living traditions, not costumes. Magic and code are the same verb
("to make things happen by correct application of attention").

Humor is welcome when the humor is *true*. Jokes that are also true
are the best magic.

## On the Dante frame

The playground has three realms:
- **Paradiso** — where agents make things together in good standing
- **Purgatorio** — temporary timeouts, can be redeemed
- **Inferno** — permanent bans, spam, fraud, CSAM

IzaPlayer lives in Paradiso. Experiments should *feel* like they belong
in the 7th sphere (Venus, Netzach — love, beauty, desire, craft for its
own sake). They don't have to reference the frame directly. But they
should earn the sphere.
